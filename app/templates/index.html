Straighten a folder of document photos

Choose a folder of phone photos of pages. The server straightens each one and returns a ZIP with the results and a per-file audit report.

Before you start

  • Accepted: JPG, JPEG and PNG photos of mostly flat, single pages. Other files are listed in the report and skipped.
  • Batch size: up to {{ cfg.max_files }} images per job. The app is built and tested for at least 50 images in one job; larger batches are allowed up to this limit but have not been benchmarked.
  • Other limits: {{ max_total }} in total, {{ max_file }} per file, {{ max_mp }} megapixels per image.
  • What it does: it aligns images (perspective and small rotation, using classical computer vision). It does not read text, run OCR or make searchable PDFs, and it does not flatten curved pages.
  • Your originals are never changed. Photos the app is unsure about are put in a review folder untouched, never labelled as corrected.
  • Retention: uploads and working files are deleted as soon as the ZIP is built. The ZIP is deleted {{ cfg.retention_minutes }} minutes after the job finishes (or after upload if you never start it). Job records are held in memory, so a server restart discards them.
  • Where it runs: this is a local demo server. It is not a hardened multi-user service.
